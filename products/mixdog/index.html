실력은 그대로,토큰은 63% 덜 씁니다.

Mixdog은 무료 오픈소스 데스크톱 코딩 에이전트입니다. 별도 결제 없이 이미 이용 중인 Claude, ChatGPT, Grok 구독을 연결해 바로 쓸 수 있습니다.

Windows용 다운로드 ↓ macOS용 다운로드 GitHub ↗

무료 · Apache-2.0 라이선스 · Windows x64, Apple Silicon Mac

코딩부터 문서 작업까지, 창 하나에서.

같은 점수, 적은 토큰

Terminal-Bench 2.1 과제 89개를 같은 모델로 실행했을 때 성공률은 86.5%로 Codex CLI(86.1%)와 비슷했고, 전체 토큰은 63% 적게 썼습니다.

여러 모델을 한 팀으로

고성능 모델이 계획을 세우면, 저렴한 모델 여럿이 검색과 수정, 리뷰를 동시에 맡습니다.

에디터, 터미널, Git을 한곳에

코드 편집부터 테스트, 커밋, PR 생성까지 앱을 벗어나지 않고 끝냅니다.

휴대폰에서 이어서

종단간 암호화된 모바일 원격 제어로 밖에서도 작업을 확인하고 지시합니다.

코드 밖의 일도

브라우저와 데스크톱 앱을 직접 조작하고, Word·Excel·PowerPoint·PDF 문서를 작성하고 편집합니다.

내 GPU로 로컬 모델

앱 안에서 모델을 내려받아 내 PC에서 직접 실행할 수 있습니다.

여러 작업을 동시에.

창을 여러 개로 나누어 각각 독립된 세션에 다른 작업을 맡길 수 있습니다. 한쪽에서 기능을 개발하는 동안 다른 쪽에서 버그를 수정합니다.

토큰이 어디에 쓰였는지 한눈에 보입니다.

제공사와 모델별 토큰 사용량, 비용, 구독 한도, 초기화 시점을 한 화면에서 확인합니다.
